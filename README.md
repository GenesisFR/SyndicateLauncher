# SyndicateLauncher

<img width="394" height="152" alt="image" src="https://github.com/user-attachments/assets/f2ceb77e-31c7-4cbc-bac2-01451e17d99c" />

An AutoHotkey 2 script that allows you to launch the 2012 reboot of Syndicate when it refuses to run due to error code "0xc0000142".

If the config file is missing, it'll look for the game executable in the current directory and use the following default values:  

```
attempts=50  
timeBetweenAttempts=50  
useRunWait=0
```
